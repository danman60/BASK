# M1 — Web demo build (the five loops)
## Execution plan. Parents: IMPLEMENTATION_SPEC.md (M1 scope, §0 demo mandate), DESIGN_SPEC.md (visual acceptance bar), PITCH.md (the beats these screens must serve).

**Goal:** the product Nick sees. Every surface in the pitch script, real and interactive, on the M0 spine.

**Visual acceptance bar:** `mockups/*.html` + their PNGs. A screen is not done until a screenshot of it sits beside the mockup without embarrassment — same warmth, hierarchy, restraint. Tokens/components already exist (`@bask/tokens`, `@bask/ui`); do not re-derive them.

**Executor notes:** deviations → `## Deviations` in this file. Steps are intent + constraints; component internals are your judgment. Screenshot every iteration and DM it (`~/tg-dm.sh --file <png> "<context>"`). Assign your lane's dev port (below) — every M0 lane defaulted to 3417 and collided.

## Standing constraints (from M0, do not rediscover)
- Prisma 7 needs `@prisma/adapter-pg`. Migrate MUST use `DIRECT_DATABASE_URL` (:5432) — :6543 pgbouncer hangs silently forever. New migrations: `pnpm db:migration:new` → `pnpm db:check` → `pnpm db:deploy`. Never `prisma migrate dev`.
- Always import the shared client (`import { db } from '@bask/db'`) — never `process.env.DATABASE_URL` in a route. Route-module clients must be lazy.
- ThemeProvider lives in the ROOT layout. Don't add another.
- `packages/core/consent` is the ONE filter every Compass surface reads through. No Compass query may bypass it.
- Insight `evidence` uses the single `Evidence` zod schema from `@bask/core`. UI props read that shape — do not invent a second.
- No auth machinery (explicit non-goal until M3). Roles come from the URL/presenter panel.
- Nothing auto-sends. Guardrail validators run on every generation.
- `pnpm demo:reset` (~32s) then `demo:advance --days N` regenerates state; keep every screen working from a fresh reset.

## Merge protocol (learned from M0)
Lanes own disjoint routes/components. Shared files (root layout, nav, `packages/ui` primitives) belong to Lane 1 — other lanes request additions rather than editing. Merge order 1 → 2 → 3 → 4 → 5 → 6, running `pnpm build && pnpm typecheck && pnpm test && pnpm lint` after each. Re-verify every merged surface in a real browser: M0 proved that three separate bugs were invisible inside their own lanes and only appeared once merged.

## Exit gate
`pnpm demo:verify` green on the full PITCH.md path · every mockup-backed screen screenshotted beside its mockup and DM'd · a non-technical tester completes check-in + campaign creation unaided · all five loops runnable from a fresh `demo:reset` · consent tier flip demonstrably changes Compass · build/typecheck/lint/test green.

- 2026-08-07 · **Lane 1** · **Skipped `demo:reset` / `demo:advance --days 5`.** The shared CC&SS database was already at exactly that state (`virtual_today` 2026-08-11, briefs for 08-07…08-11, 8 insights, all six detectors fired) and five other lanes were building against it concurrently — a probe caught a `TEST-LANE-C Salon` row and mid-truncate reads from another lane's reset. Resetting would have wiped their in-flight work for no gain. Verified the required state instead of recreating it.
- 2026-08-07 · **Lane 1** · **Insight state transitions are Next.js server actions** (`apps/web/src/app/(bask)/actions.ts`), not tRPC procedures. `packages/api/src/routers/domains.ts` is a file every lane wants to edit; three writes against columns the M0 schema already has do not justify a shared-file conflict. `todayRouter` is left as the M0 stub for whoever needs a typed client (mobile, M2).
- 2026-08-07 · **Lane 1** · **Route group `(bask)/` added** — `/` stays `/`, and every salon-facing surface inherits the shell. Lanes 2–4 should put their routes under `apps/web/src/app/(bask)/` to get the nav for free. `/compass` and `/dev/*` stay outside it.
- 2026-08-07 · **Lane 1** · **`<Guided>` gained an `affordance` prop** (`default | quiet | none`). Four permanent `?` marks down a 320px rail plus one on every chip and sparkline read as clutter next to mockup 01. Quiet/none keep the identical keyboard + screen-reader contract and reveal the mark on hover/focus. Existing `<Guided>` calls are unchanged (`default`).
- 2026-08-07 · **Lane 1** · **Location-comparison card renders a teaching empty state for the seeded multi-location org.** Aurora Collective (the only org with >1 salon) has 0 visits, 0 sales, 0 memberships, 0 customers on both salons — it is seeded as a Compass org shape only. The card, its metric math and its wiring are done; `$0 vs $0` would read as a broken metric, so it teaches instead. **Needs a `packages/db` fixture change (out of this lane) to show real numbers.**
- 2026-08-07 · **Lane 1** · **Mobile keeps a third affordance the mockup does not have.** Mockup 05 is a two-button native card; a browser has no swipe-to-dismiss, so Dismiss survives at 390px as a quiet ghost pushed to the far edge — the row still reads as a button pair. The bottom tab bar likewise carries the real six-destination web IA rather than mockup 05's four native tabs (Daybreak/Pulse/Scan/Campaigns), which are the Expo shell's IA, not the web app's.
- 2026-08-07 · **Lane 1** · **"Next up" reads today's visits after the pulse cut-off hour (11:00 salon-local).** The fixtures carry no future-dated bookings — `session` rows are all `completed` history — so "the rest of today" is the only honest source. When it is empty the card teaches. Lane 2's check-in flow will fill it naturally.
- 2026-08-07 · **Lane 1** · **Bug found in `packages/api/src/context.ts` (NOT fixed from this lane).** `db.salon.findFirst({ where: { OR: [{ slug: x }, { id: x }] } })` throws `invalid input syntax for type uuid` when `?salon=` is a slug — `salon.id` is `@db.Uuid`, and Postgres type-errors rather than returning no rows, taking the whole request down. `apps/web/src/lib/salon-scope.ts` guards with a UUID test; the tRPC context still needs the same guard.
- 2026-08-07 · **Lane 1** · **Pre-existing hydration warning left alone.** `ThemeScript` stamps `data-theme` on `<html>` before paint, which React 19 reports as a server/client attribute mismatch. It reproduces on `/dev/design` (an M0 route) as well as on `/`, so it is root-layout behaviour, not Lane 1's. Cosmetic in dev only — worth a look before the pitch.
