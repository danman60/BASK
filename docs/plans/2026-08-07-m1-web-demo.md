# M1 — Web demo build (the five loops)
## Execution plan. Parents: IMPLEMENTATION_SPEC.md (M1 scope, §0 demo mandate), DESIGN_SPEC.md (visual acceptance bar), PITCH.md (the beats these screens must serve).

**Goal:** the product Nick sees. Every surface in the pitch script, real and interactive, on the M0 spine.

**Visual acceptance bar:** `mockups/*.html` + their PNGs. A screen is not done until a screenshot of it sits beside the mockup without embarrassment — same warmth, hierarchy, restraint. Tokens/components already exist (`@bask/tokens`, `@bask/ui`); do not re-derive them.

**Executor notes:** deviations → `## Deviations` in this file. Steps are intent + constraints; component internals are your judgment. Screenshot every iteration and DM it (`~/tg-dm.sh --file <png> "<context>"`). Assign your lane's dev port (below) — every M0 lane defaulted to 3417 and collided.

## Standing constraints (from M0, do not rediscover)
- Prisma 7 needs `@prisma/adapter-pg`. Migrate MUST use `DIRECT_DATABASE_URL` (:5432) — :6543 pgbouncer hangs silently forever. New migrations: `pnpm db:migration:new` → `pnpm db:check` → `pnpm db:deploy`. Never `prisma migrate dev`.
- Always import the shared client (`import { db } from '@bask/db'`) — never `process.env.DATABASE_URL` in a route. Route-module clients must be lazy.
- ThemeProvider lives in the ROOT layout. Don't add another.
- `packages/core/consent` is the ONE filter every Compass surface reads through. No Compass query may bypass it.
- Insight `evidence` uses the single `Evidence` zod schema from `@bask/core`. UI props read that shape — do not invent a second.
- No auth machinery (explicit non-goal until M3). Roles come from the URL/presenter panel.
- Nothing auto-sends. Guardrail validators run on every generation.
- `pnpm demo:reset` (~32s) then `demo:advance --days N` regenerates state; keep every screen working from a fresh reset.

## Merge protocol (learned from M0)
Lanes own disjoint routes/components. Shared files (root layout, nav, `packages/ui` primitives) belong to Lane 1 — other lanes request additions rather than editing. Merge order 1 → 2 → 3 → 4 → 5 → 6, running `pnpm build && pnpm typecheck && pnpm test && pnpm lint` after each. Re-verify every merged surface in a real browser: M0 proved that three separate bugs were invisible inside their own lanes and only appeared once merged.

## Exit gate
`pnpm demo:verify` green on the full PITCH.md path · every mockup-backed screen screenshotted beside its mockup and DM'd · a non-technical tester completes check-in + campaign creation unaided · all five loops runnable from a fresh `demo:reset` · consent tier flip demonstrably changes Compass · build/typecheck/lint/test green.

## Deviations
(log here — date · lane · what changed · why)

- 2026-08-07 · L2 · **Three new tables + migration `20260807000003_floor_booking_waiver_handoff`** (`Booking`, `WaiverSignature`, `ShiftHandoff`, enum `BookingState`), with matching RLS `salon_isolation` policies. The schedule, the real waiver artefact and the handoff all had M1 scope but no schema — `customer.waiver_signed_at` is a flag, not a signature you can show someone. Additive only; nothing existing changed.
- 2026-08-07 · L2 · **Bookings are seeded lazily by the app (`ensureBookings`), not by `packages/db/fixtures`.** Fixture rows would move the `demo:reset` checksum that `tests/determinism.test.ts` pins, and the schedule is a Floor concern rather than a story arc. Idempotent per day, so a rebooking made in the demo is never overwritten by a refresh. Verified: checksum after the change is unchanged (`983ba939…`).
- 2026-08-07 · L2 · **`demo-reset.ts` `DELETE_ORDER` gained the three Floor tables.** They are app-owned, not fixture data, but they hang off customer/room/salon; that file's own rule is to name tables explicitly rather than lean on cascade order.
- 2026-08-07 · L2 · **Server actions, not the `packages/api` `floor` router.** That router is still an M0 stub with only `surface()`, and `packages/api` is shared — same rationale the M0 harness recorded. The actions are thin wrappers over the engine and become tRPC procedures without the UI changing.
- 2026-08-07 · L2 · **Floor copy lives in `apps/web/src/app/floor/copy.ts`, not the `@bask/ui` guidance dictionary.** The merge protocol gives `packages/ui` to lane 1. Same register and same discipline (no inline strings); promoting the keys later is a move, not a rewrite. **Requested for the shared dictionary:** Floor tips (`scannerMode`, `walkInVsBooked`, `capacityShading`), metric `retailAttachment` reuse on the handoff card.
- 2026-08-07 · L2 · **`/dev/floor/lib/*` moved to `apps/web/src/server/floor/*`** and `FloorEngine` is now constructed with a `FloorTarget`. `/floor` runs `hero` (seeded Sunset Ridge, non-destructive reset — its sessions are the history every insight is computed from); `/dev/floor` keeps its `harness` sandbox unchanged.
- 2026-08-07 · L2 · **Simulated manual starts: 300s → 3600s mean on the hero salon** (harness keeps 300s). Several services map to exactly one room — Level 2 UV is only ever Bed 2 — so at the harness cadence the simulator takes the bed out from under the person checking a customer into it. Rare enough to still prove reconciliation, not often enough to fight the operator.
- 2026-08-07 · L2 · **The session-timing verdict warns; it does not block, and it is UV-only.** Two bugs found in testing: the 24-hour gap was being computed from *any* last session (so a hydromassage yesterday refused a spray tan today), and a disabled start button was a hard refusal the specs never asked for. The rule is stated loudly against the chosen service; the decision stays with the staffer.
- 2026-08-07 · L2 · **Shift Handoff is a topbar action opening a right-side sheet, not a fifth tab** — mockup 02's segmented pill is four tabs and that pill is the surface's chrome.
- 2026-08-07 · L2 · **`refresh()` removed from every Floor mutation.** It re-ran the page's eight queries on every scan and sale for no gain: the client already updates optimistically and polls state. Floor speed is sacred. The handoff sheet recomputes its own numbers on open instead.
- 2026-08-07 · L2 · **Engine `globalThis` cache is now keyed by a per-module-evaluation token, and `dispose()` clears the ticker.** Without it, every dev edit to the engine was silently ignored — `getFloorEngine` kept returning the instance built by the previous evaluation of the module, holding a `SimulatedDriver` whose units had drifted from the database. This cost real debugging time; it will cost the next person more.
- 2026-08-07 · L2 · **`startSession` re-hydrates and retries once when the driver refuses a room the rows say is free.** `demo:reset` between rehearsals leaves the simulated units holding sessions the database no longer has. The harness had a "Re-seed" button for this; a front desk cannot be asked to diagnose a stale driver.
- 2026-08-07 · L2 · **Wedge listener: a slow inter-key gap poisons the whole burst rather than starting a fresh window.** The restart version truncates a stalled 12-digit UPC into a 7-digit string that is still long enough to look like a barcode — which resolves to nothing, or to a different product. A missed scan makes somebody scan again; a truncated scan puts the wrong bottle in the cart.

### Known issue for lane 1 (not lane 2's to fix)
`/floor` (and every other route) trips a hydration mismatch on `<html data-theme>` — `ThemeScript` in the root layout sets it before React hydrates, and the dev overlay reports "1 issue". Cosmetic in dev, but it should not ship on a pitch build.
